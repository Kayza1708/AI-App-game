# Gem Economy Audit

Current predictable free sources are Daily login (normally 1/day, 3 on each seventh login), selected Daily missions (commonly 0–2/day depending on rotation), weekly goals (approximately 3–8/week), monthly goals (approximately 10–22/month), streak rewards, gameplay caches, and an optional capped Daily Gems rewarded placement.

| Profile | Approx. Gems/day | Approx. Gems/week | Approx. Gems/month |
| --- | ---: | ---: | ---: |
| Casual F2P (login + partial missions) | 1–2 | 8–14 | 35–60 |
| Active F2P (primary missions + weekly/monthly) | 2–4 | 18–30 | 80–130 |
| Ad-using active F2P | 3–5 | 25–37 | 110–160 |

At these provisional rates, 500 Gems represents roughly 3–6 months for casual play, 4–7 weeks for active play, and about 3–5 weeks with consistent optional ads. That makes 500 Gems a long-term utility purchase, not a daily purchase. Current small sinks (5–40 Gems) range from several days to several weeks. These are estimates for telemetry validation, not a Gem rebalance.

Telemetry records earned/spent totals, event source/sink, net balance, spending frequency, and hoarding. Developer grants remain non-natural. No real-money transaction or mandatory Gem wall exists.
