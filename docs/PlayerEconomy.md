# Future Player Economy

The reserved **AI Exchange** is not implemented. Item instances include unique identity, owner, creation time, source, binding, tradeability, and future roll metadata so a later migration is avoidable.

Real trading requires authenticated accounts, a database, server-authoritative ownership and balances, atomic transaction validation, marketplace tax, anti-cheat, rate limiting, dispute recovery, and market-abuse detection. Client-trusted listings are explicitly disabled; imported or edited saves must never create valid exchange ownership.

Future Gems may fund listing convenience or cosmetics, but should not purchase randomized competitive power. Salvage, materials, crafting blueprints, rerolls, fusion, and Item Sets remain documented extension points rather than dead UI.
