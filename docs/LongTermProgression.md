# Long-Term Progression

The progression stack is Run economy → Development Cycle/INT → Model and Tech specialization → Items/Patents → missions and collection → late Breakthrough/Insight. Fresh players still see only Dashboard, Hardware, TinyChat, and Objectives. Missions unlock at 4 lifetime INT and Model equipment at 15, using centralized feature gates.

Daily, weekly, and monthly missions use UTC period identifiers saved with the account. Generation filters out locked mechanics and survives reloads and clock boundaries. This local-only design prevents accidental duplicate claims in normal use but is not a security boundary.

Artifacts, crafting, salvage, seasonal challenges, passes, expeditions, profiles, leaderboards, community events, and collections have schema or documentation hooks only. Offline reconciliation must eventually advance production, Training, Research, Patents, mission periods, and playtime-based boosts from one authoritative elapsed-time calculation.
