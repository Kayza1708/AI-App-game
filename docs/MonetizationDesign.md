# Monetization Design

- No forced ads, mandatory purchase wall, or paid randomized loot boxes.
- Gems buy convenience, time, and flexibility; full progression remains achievable without payment.
- Rewarded boosts require an explicit button press. The web provider is a clearly labelled local simulation with cooldowns and daily caps. It never invokes automatically.
- Real-money products are catalog metadata only and display “Store integration not active in web development build.” No transaction is simulated.
- Gameplay caches are earned, never sold. Future native IAP and ad providers must validate completion before rewards are granted.

Current free Gem sources include missions, login rewards, and landmark progression. Current sinks include an Item slot, inventory expansion, and bounded Training/Research surges. Balance values remain centralized.
